# Fermentation CFD Studio — Public Demonstration

A public, browser-only demonstration of a fermentation CFD research interface. **Illustrative spatial flow previews are not validated Navier–Stokes CFD.** This repository contains a curated static frontend, not the private research project, experiment data, proprietary solver, or server credentials.

## Online site

Once GitHub Pages is enabled and deployed, the expected public URL is:

https://xuyuchen231-stack.github.io/-Fermentation-CFD-demo/

The leading hyphen in the repository name is intentional and is part of the URL.

## Published features

- Spatial field explorer, analytical flow preview and imported field visualization
- Editable 3 L and 5 L illustrative reactor designs
- Scientific multi-panel figures with explicit provenance
- Field comparisons for compatible imported cases

## Publishing

Open **Settings → Pages → Build and deployment → Source → GitHub Actions** for this public repository. The deployment workflow publishes only reviewed static files. Do not upload private experimental data or secrets.
